# Backend Express.js & Swagger OpenAPI

O backend do **Aresta** foi refatorado para o ecossistema **Node.js** utilizando **Express.js**, **TypeScript**, **Prisma ORM** e documentação interativa com **Swagger (OpenAPI 3.0)**, seguindo rigorosamente o padrão arquitetural **Layered MVC**.

---

## 📖 Documentação Swagger (OpenAPI 3.0)

A documentação interativa da API está disponível via **Swagger UI** servida diretamente pelo Express:

- **Swagger UI**: [http://localhost:7070/api-docs](http://localhost:7070/api-docs)
- **JSON da Especificação**: [http://localhost:7070/api-docs.json](http://localhost:7070/api-docs.json)

As anotações OpenAPI 3.0 estão integradas diretamente nos *controllers* através do `swagger-jsdoc`, permitindo testar requisições autenticadas usando o botão **Authorize** e informando `Bearer {token}`.

## 🔒 Variáveis de Ambiente & Segurança

O arquivo `.env` deve ser criado com base no `.env.example`:

```bash
# Porta do servidor backend Express
PORT=7070

# URL de conexão com o banco SQLite (Prisma)
DATABASE_URL="file:./dev.db"

# Segredo para assinatura de tokens JWT
JWT_SECRET="aresta_super_secret_jwt_key_change_in_production"

# Modo de desenvolvimento / debug
DEBUG=true

# Diretório de armazenamento de capas e livros
STORAGE_PATH="./storage"
```

O arquivo `src/config/env.example.ts` exporta tipos TypeScript para validação em tempo de desenvolvimento. Arquivos de banco de dados (`*.sqlite`, `*.db`) e variáveis com segredos (`.env`) são ignorados pelo `.gitignore`.

## 🚀 Como Executar o Backend

### 1. Instalar dependências
```bash
cd aresta-back-node
npm install
```

### 2. Sincronizar o Banco e Executar Seed
```bash
npx prisma generate
npx prisma db push
npx prisma db seed
```

### 3. Iniciar em Modo Desenvolvimento
```bash
npm run dev
```

O servidor estará ouvindo na porta `7070`:
- **Health Check**: `http://localhost:7070/api/health`
- **Swagger Docs**: `http://localhost:7070/api-docs`

## 🧪 Testes Automatizados (Vitest + Supertest)

O backend conta com uma suíte de testes de integração cobrindo fluxos de autenticação, saúde, catálogo de livros, gerenciamento de usuários e nós/arestas do grafo.

### Executar os testes:
```bash
cd aresta-back-node
npm test
```

### Executar em modo observação contínua (*watch*):
```bash
npm run test:watch
```
