# Sistemas Utilizados

Neste projeto utilizamos os seguintes sistemas e ferramentas para desenvolvimento, integração contínua e documentação:

## Controle de Versão & CI/CD
- **GitHub Actions** – Pipelines de integração e entrega contínua para build, testes e deploy.

## API & IA
- **Gemini API** – API de IA da Google utilizada para automação e suporte de funcionalidades avançadas.

## Documentação
- **Mintlify** – Plataforma de documentação que gera documentação automática e mantém o conteúdo atualizado.

## Outros sistemas (já presentes no repositório)
- **Node.js / npm** – Ambiente de execução JavaScript e gerenciamento de dependências.
- **Nuxt 3** – Framework Vue para o front‑end.
- **Playwright** – Ferramenta de testes end‑to‑end.
- **Vitest** – Test runner para testes unitários.
- **PDFBox** – Biblioteca Java para renderizar PDFs.
- **EPUB.js** – Biblioteca JavaScript para renderizar ePub files.
- **Three.js** – Biblioteca JavaScript para animações 3D.
> Esta documentação deve ser mantida atualizada sempre que novos sistemas forem incorporados ao projeto.
