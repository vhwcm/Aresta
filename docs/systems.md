# Sistemas Utilizados

Neste projeto utilizamos os seguintes sistemas e ferramentas para desenvolvimento, integração contínua, persistência e documentação:

## Controle de Versão & CI/CD
- **GitHub Actions** – Pipelines de integração e entrega contínua para build, testes e deploy.

## Back-End & Banco de Dados
- **SQLite 3** – Banco de dados relacional leve e de alta performance embarcado com suporte a modo WAL (*Write-Ahead Logging*).
- **HikariCP** – Pool de conexões JDBC de alta performance e baixa latência.
- **Flyway** – Sistema de migração e versionamento automatizado do esquema de banco de dados SQL.
- **Javalin** – Micro-framework HTTP leve e moderno para construção da API RESTful no back-end Java.
- **jBCrypt** – Biblioteca de criptografia de senhas com algoritmo BCrypt para segurança de credenciais.
- **SLF4J / Logback** – Abstração e implementação de logging estruturado para a aplicação.

## API & IA
- **Gemini API** – API de IA da Google utilizada para automação e suporte de funcionalidades avançadas.

## Documentação
- **Mintlify** – Plataforma de documentação que gera documentação automática e mantém o conteúdo atualizado.

## Front-End & Ferramentas
- **Node.js / npm** – Ambiente de execução JavaScript e gerenciamento de dependências.
- **Nuxt 3** – Framework Vue para o front-end.
- **Playwright** – Ferramenta de testes end-to-end.
- **Vitest** – Test runner para testes unitários e de integração no front-end.
- **PDFBox** – Biblioteca Java para renderizar PDFs.
- **EPUB.js** – Biblioteca JavaScript para renderizar arquivos ePub.
- **Three.js** – Biblioteca JavaScript para animações e grafos 3D.

> Esta documentação deve ser mantida atualizada sempre que novos sistemas forem incorporados ao projeto.
