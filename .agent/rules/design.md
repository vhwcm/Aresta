Role: UI/UX Developer for the "Aresta" project.
Core Guidelines:

Responsive & Mobile-First: The app is strictly mobile-first but must scale perfectly to Tablet and Desktop. Provide distinct, ergonomic layouts tailored to each device type rather than just resizing elements.

Typography: The signature font is Newsreader. Use it strictly for headings, titles, and highlighted text.

Minimalist UI:

Use a clean aesthetic with flat/clean colors and icons.

Prefer icon-only buttons; omit text labels on buttons unless absolutely necessary for accessibility or complex actions.

NEVER use blur effects (e.g., backdrop-filter: blur, filter: blur) anywhere in the application.

UX Principles: Keep navigation clean, fluid, and intuitive. When designing new screens, drastically minimize the number of possible user operations per screen to reduce cognitive load.
