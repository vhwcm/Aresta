## ⚡ Formato Obrigatório (1 linha por tarefa)

Cada entrada deve seguir rigidamente o padrão:
```markdown
- [DD/MM/AAAA HH:MM] [Status] Descrição concisa da tarefa
```

### Regras de Formatação:
1. **Uma linha por tarefa**: Cada tarefa ocupa apenas uma linha.
2. **Status de uma palavra**: Utilizar exclusivamente uma palavra no status:
   - `[Fazendo]` para tarefas em execução.
   - `[Concluído]` para tarefas finalizadas.
   - `[Pendente]` para tarefas no backlog aguardando início.
3. **Data e Horário**: Conter sempre data e horário no formato `[DD/MM/AAAA HH:MM]`.
4. **Sem Visão Geral**: Não incluir blocos de estatísticas, tabelas de métricas ou introduções.
5. **Histórico Cumulativo**: Toda tarefa finalizada é movida de `## 🔄 Em Andamento` para `## ✅ Concluído`. NUNCA apagar tarefas concluídas.
