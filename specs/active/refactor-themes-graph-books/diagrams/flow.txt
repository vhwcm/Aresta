  ┌────────────────────────────────────────────────────────────────────────┐

  │ - Cria registro na tabela `Book`                                       │
  │ - Coleta lista de temas existentes com embeddings                      │
  │ - Invoca gRPC AnalyzeBook no microserviço Go                           │
  └──────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     │ 3. gRPC AnalyzeBook(Title, Author, ExistingThemes)
                                     ▼
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Microserviço Go (aresta-ocr / aresta-ai)                               │
  │ - Gemini 2.5 Flash + Google Search Grounding:                          │
  │     Busca dados públicos do livro, contexto e tópicos                  │
  │ - Gera Resumo oficial                                                  │
  │ - Gera Embeddings dos temas e calcula similaridade de cosseno          │
  │ - Determina temas existentes + novos temas e subtemas hierárquicos     │
  └──────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     │ 4. Retorna { Summary, MatchedThemes, NewThemesWithHierarchy }
                                     ▼
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Backend Node.js (Persistência no SQLite via Prisma)                    │
  │ - Salva dados em `BookPublicInfo` (autor, resumo)                      │
  │ - Insere novos temas na tabela global `Theme`                          │
  │ - Insere vínculos pai/filho em `ThemeHierarchy`                       │
  │ - Insere vínculos livro-tema em `BookTheme`                            │
  └──────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     │ 5. Resposta 201 Created com Livro + Temas
                                     ▼
