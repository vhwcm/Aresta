FLUXO DE DADOS & ARQUITETURA: REFATORAÇÃO DE TEMAS, LIVROS E GRAFO DE CONHECIMENTO
================================================================================

1. FLUXO DE CADASTRO E ATRIBUIÇÃO DE TEMAS (DIRETO E DETERMINÍSTICO)
--------------------------------------------------------------------------------

  [ Viktor / Usuário ]
         │
         │ 1. Upload PDF/EPUB + Title + Author
         ▼
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Frontend Nuxt (/library ou /admin/upload)                              │
  │ - Upload do livro                                                      │
  │ - Envia dados para o Backend API                                       │
  └──────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     │ 2. Salva arquivo e cria registro
                                     ▼
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Backend Node.js (Prisma)                                               │
  │ - Salva arquivo localmente / extrai imagem de capa                     │
  │ - Cria registro na tabela `Book` e `BookPublicInfo`                    │
  │ - Cria vínculo em `UserBook`                                           │
  └──────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     │ 3. Livro disponível na Estante
                                     ▼
  ┌────────────────────────────────────────────────────────────────────────┐
  │ Estante & Grafo de Conhecimento                                        │
  │ - Usuário abre modal de tags/temas do livro                            │
  │ - Seleciona ou cria temas do Catálogo Global (PUT user-books/:id/themes)│
  │ - Grafo atualiza arestas (livro <-> tema) instantaneamente              │
  └────────────────────────────────────────────────────────────────────────┘
