 │           PUT /api/user-settings (Node.js API)         │

 │ 2. Validação via Zod (updateUserSettingsSchema)        │
 │ 3. Upsert no Prisma DB:                                │
 │    - desktop_home_graph_open                           │
 │    - desktop_reader_graph_open                         │
 │    - theme_mode                                        │
 │    - epub_font_size                                    │
 │    - epub_font_family                                  │
